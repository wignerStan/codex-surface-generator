# v11 generated examples

These files are generated by `python tools/build_v11_assets.py`.

- `evolution-contract.identity-split.json` shows independent thread and turn identity.
- `evolution-contract.legacy-combined-identity.json` captures the older combined gate.
- `semantic-diff.identity-split.json` demonstrates the change a current-main canary sees.
- `evolution-contract.unclassified-expression.json` demonstrates fail-visible semantics.
- `source-registry.default.json` is the generated registry behind all source providers.
- `source-registry.overlay.example.json` shows a file-move override without code edits.
